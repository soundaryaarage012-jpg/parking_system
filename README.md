# 🚗 Smart Parking Space Tracker

A Smart Parking Space Tracker is a web-based application that helps users find available parking spaces quickly and efficiently. The system provides real-time parking availability, QR code-based parking access, AI-powered analytics, and an interactive dashboard for users and administrators.

---

## 📌 Features

### 👤 User Features
- User Registration & Login
- View Available Parking Slots
- Reserve Parking Spaces
- QR Code Generation for Parking
- Parking History
- User Profile Management
- Notifications
- AI Chat Assistant

### 🔐 Admin Features
- Admin Dashboard
- Manage Users

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/parking_system.git
```

Move into the project folder

```bash
cd parking_system
```

Create Virtual Environment

```bash
python3 -m venv venv
```

Activate Virtual Environment

Linux/macOS

```bash
source venv/bin/activate
```

Windows

```bash
venv\Scripts\activate
```

Install Dependencies

```bash
pip install -r requirements.txt
```

Run the Application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
